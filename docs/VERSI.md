# Versi terpasang

Isi setelah instalasi (jalankan perintah di terminal).

| Komponen | Versi | Cara cek |
| --- | --- | --- |
| Node | | node -v |
| npm | | npm -v |
| Angular CLI | | ng version |
| Express | | npm ls express (di folder backend) |
| TypeScript | | npx tsc -v |
| SQL Server 2024 (perusahaan) | | SELECT @@VERSION (jalankan lewat klien SQL) |
