# Frontend (Angular)

Folder ini sengaja kosong. Buat aplikasi dengan Angular CLI terbaru dari folder ini:

```
npm install -g @angular/cli
ng new portal-psikotes-web --directory . --style=scss --routing --ssr=false
```

Lalu catat versi di `docs/VERSI.md`.

Rencana halaman (mengikuti prototipe UI lo-fi):
- Portal peserta: pilih tes, verifikasi token, instruksi, latihan, TIU 5, TIU 6, Koran, kirim, selesai.
- Dashboard HC: overview, token dan jadwal, hasil dan laporan.

Ionic hanya ditambahkan bila tim IT mewajibkannya.
